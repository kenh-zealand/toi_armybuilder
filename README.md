# Tide of War Army Builder

Small static army builder for Tide of War with:

- scenario-based roster limits
- expansion enable/disable toggles
- faction filtering
- live roster validation

## Run

Open `index.html` from the repository root in a browser, or serve the directory
with a simple static server such as `python3 -m http.server` and visit
`/index.html`.

## Test

npm test
